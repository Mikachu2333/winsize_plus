# WinSizeP

中文 | [English](README.en.md)

Windows 窗口位置与大小调整工具，支持 Alt 快捷键、鼠标拖动、屏幕分区、十字线、键鼠标注和命令行。

## 使用

运行 `winsizep.exe`，从托盘菜单打开设置。设置自动保存并应用；“通用”页的“打开配置文件”使用 `notepad.exe` 打开程序旁的 `winsizep_config.toml`。请将程序放在当前用户可写的目录中。

默认使用左 Alt：长按 2 秒后显示提示框并启用快捷键和鼠标操作，再配合按键；也可双击 Alt 后松开，再按对应键。“通用”页可设置长按延迟（`general.alt_hold_ms`，0–60000 毫秒，0 为立即触发）。延迟结束前输入组合键会交给应用，并取消本次长按触发。分区预览与提示框从显示时起默认停留 3 秒，长按时松开 Alt 可提前关闭。

| 默认操作 | 作用 |
| --- | --- |
| Alt + 左键拖动 | 移动窗口 |
| Alt + 右键拖动 | 固定左上角，调整窗口大小 |
| Alt + 右键点击 | 按鼠标所在的九宫格位置调整窗口 |
| Alt + Q/W/E、A/S/D、Z/X/C | 使用九个分区预设；S 默认居中 |
| Alt + P | 置顶 / 取消置顶 |
| Alt + L | 显示 / 隐藏十字线 |
| Alt + M / Alt + K | 开启 / 关闭鼠标标注、键盘标注 |
| Alt + U | 忽略当前窗口 |
| Alt + 反引号（\`） | 输入指令，Enter 执行 |
| Alt + H | 显示当前快捷键帮助 |
| Esc | 关闭提示、取消操作或重置聚焦预览 |

鼠标操作针对按下 Alt 时的前台窗口。可在设置中更换 Alt 侧键、拖动按键及快捷键。按键名称不区分大小写，显示统一为 `W`、`F12`、`Insert` 等形式；系统保留组合键不能用于绑定。

## 设置与预览

- 分区可增加、删除、重命名和重新绑定。预览中的区域名下方会居中显示当前快捷键，例如 `FullTop` 下一行显示 `[ W ]`。
- 九宫格悬停 2 秒可预览实际区域，移出区域或按 Esc 返回九宫格。
- 提示、框线、字体、十字线和键鼠标注均可在设置中调整；示例预览在设置失焦时暂停。
- 键鼠标注默认关闭，淡出统一为 400 ms；键盘标注的停留时间可调。
- 帮助和可滚动的长提示保持显示，按 Esc 关闭。
- 自动启动和管理员权限可在设置中切换。控制管理员窗口时，WinSizeP 也需要相应权限。
- 解除窗口忽略，可从配置文件中删除对应的 `[[exclusions]]` 项。
- 默认排除 Windows 10 和 11 的系统托盘弹出菜单。同一规则内的非空字段需全部匹配，多条规则任意一条匹配即可排除，因此同进程的不同窗口类可分别配置并同时生效。

## 分区与配置

分区格式为 `x|y|width|height[|monitor]`，例如 `0|0|50sw|50sh` 表示左上四分之一。省略屏号或使用 0 时跟随鼠标所在屏幕。

| 单位 | 含义 |
| --- | --- |
| sw / sh | 工作区宽 / 高的百分比 |
| ww / wh | 当前窗口宽 / 高的百分比 |
| vw / vh | 虚拟桌面宽 / 高的百分比 |
| 无单位 | 像素 |

支持 `50sw-8` 等表达式。九宫格从左上到右下编号 1–9，屏幕专属格号为“屏号 × 10 + 格号”：

```toml
[grid]
7 = "LeftBottom"
37 = "Center" # 第 3 屏的左下格
```

区域可使用中文名称；区域和命令名称不能与内置动作重名。配置与管道输入建议使用 UTF-8；全局指令输入使用英文字母、数字、空格、连字符和下划线。

## 命令行

```powershell
.\winsizep.exe --name notepad.exe --preset Center
.\winsizep.exe --pid 123 --location 100,200 --size 900,600
.\winsizep.exe --hwnd 0x1234 --top on
.\winsizep.exe --settings
.\winsizep.exe --check
123, 456 | .\winsizep.exe --stdin --preset Center
```

可按 `--pid`、`--hwnd`、`--name`、`--class`、`--title` 筛选窗口；省略筛选条件时操作前台窗口。`--stdin` 每行接受一组参数或一个 PID。用 `--check` 检查配置，托盘帮助显示当前绑定。

## 构建

需要 Windows x64、Rust 1.88+ MSVC 工具链和 Windows SDK；程序支持 Windows 10 1703 及更新版本。

```powershell
cargo build --release
cargo test
```

生成程序：`target/release/winsizep.exe`。
