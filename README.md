# WinSizeP

中文 | [English](README.en.md)

Windows 窗口位置与大小调整工具，支持 Alt 快捷键、鼠标拖动、屏幕分区和命令行。

## 使用

运行 `winsizep.exe`，从托盘菜单打开设置。设置自动保存并应用，也可以直接编辑程序旁的 `winsizep_config.toml`。程序只运行一个常驻实例。

默认使用左 Alt。可按住 Alt 配合按键，也可双击 Alt 后松开，再按对应键；双击时间跟随 Windows。按住 Alt 或双击 Alt 后，分区预览与提示框立即同步显示，默认停留 3 秒后一起关闭；长按时松开 Alt 则提前关闭。再次触发会重新计时。

| 默认操作 | 作用 |
| --- | --- |
| Alt + 左键拖动 | 移动窗口 |
| Alt + 右键拖动 | 固定左上角，调整窗口大小 |
| Alt + 右键点击屏幕位置 | 按九宫格调整窗口 |
| Alt + Q/W/E、A/S/D、Z/X/C | 使用九个预设；S 默认居中，宽高为工作区的 80% |
| Alt + P | 置顶 / 取消置顶 |
| Alt + L | 显示 / 隐藏十字线 |
| Alt + M / Alt + K | 开启 / 关闭鼠标标注、键盘标注 |
| Alt + U | 忽略当前窗口 |
| Alt + 反引号（\`） | 输入指令，Enter 执行 |
| Alt + H | 帮助；按 Esc 关闭，没有自动消失时间 |
| Esc | 关闭提示或取消操作；分区聚焦/九宫格预览回到框线 |

鼠标操作针对按下 Alt 时的前台窗口。移动和调整大小可分别关闭，也可改为左键、右键、中键或两个侧键。帮助文本随绑定更新。解除忽略需要在配置文件中删除对应的 `[[exclusions]]` 项。

帮助中的分区快捷键按功能键、数字符号键和三排字母键排列，省略没有分区绑定的排。随后一行显示十字线操作，紧接下一行同时显示鼠标、键盘标注快捷键；这两行作为一个整体，前后各空一行，再列其他按键。提示框按实际字体分别计算按键列和区域名列的宽度，过宽时换行。

程序自身的设置窗口及其颜色选择对话框自动排除，无需添加配置。

## 设置与预览

设置包含通用、提示框、屏幕分区、标识框线、快捷操作、十字线、右键九宫格、鼠标标注、键盘标注九页。界面语言可选中文、英文或跟随系统。

- 自动启动由程序管理计划任务；改变提权选项会同步任务权限。需要时 Windows 显示 UAC 授权。
- 字体列表以对应字体显示，`SystemFont` 代表系统 UI 字体。最多添加三个回退字体，可拖动排序；字号单位为磅，提示框默认 12 磅。
- 分区可增加、删除、重命名；重命名同步修改相关绑定。桌面预览需开启预览并选中分区，离开此页后关闭。切换到其他窗口时暂停预览，返回设置窗口后恢复。
- 重叠分区选取鼠标到中心最近者，距离相同优先左上方。选中分区用半透明系统强调色填充，并显示名称；边线不加粗。
- 九宫格显示格号及对应区域名；悬停 2 秒后显示实际区域，移出区域、移到屏幕边缘或按 Esc 恢复九宫格。
- 十字线横线和竖线可分别设置颜色、透明度、宽度与缺口，也可选择“统一设置”同时修改。两轴共用一个 FPS，范围为 24–1000 的整数，默认 30，越界取边界值；静止时不持续绘制。

默认配色采用 Fluent 中性色与蓝色，交互状态使用 Windows 系统色。已有自定义颜色不会被新默认值覆盖。

鼠标标注在光标位置显示小型半透明填色图形：左右键为能拼成整圆的左右半圆，中键为圆心偏上的小长方形，滚动为方向三角形，侧键为两个小区块。颜色从 Windows 主题色派生。按住时始终显示，松开后淡出；连续滚动只延长同一个指示，不重播淡入。滚动方向跟随系统收到的滚轮事件，包含驱动层的反向设置。键盘标注显示物理按键名称、Ctrl/Alt/Shift/Win 组合键、最近按键和重复次数。标注不拦截普通输入，也不抢焦点。两项默认关闭，Alt+M、Alt+K 切换本次运行状态，设置页的“启动时启用”决定下次启动时的状态。升级会保留已有占用或禁用的快捷键。

两个标注页面均提供示例预览。鼠标可设置启动开关、图形半径（默认 9 逻辑像素）、不透明度及上下侧键显示对调。对调默认开启：X1 显示在 X2 下方；关闭后恢复 X1 在上、X2 在下，不改变实际按键动作。旧版紧凑图形在迁移时一次性缩为 2/3。动画固定约半秒，重复鼠标事件合并到已有状态，最多每 16 毫秒提交一帧；稳定长按且位置不变时不重绘，托盘菜单打开期间仍更新动画。键盘仍可设置字体、颜色、不透明度、停留及淡出时间、显示条数和屏幕角落。Esc 停止预览，设置失焦时暂停。标注按鼠标所在屏幕及其 DPI 绘制，只在内存中短暂显示，不记录到磁盘；键盘标注显示按键名称，不显示输入法组合后的文本。交互设计参考 KeyCastOW。

普通权限运行时不尝试控制权限更高的窗口，切回普通窗口后仍可使用快捷键。输入线程会在空闲时校正遗漏的 Alt/鼠标松开状态；长时间停顿恢复后重装钩子并取消未完成手势。“Input thread did not respond”表示内部命令等待超过两秒，严重系统卡顿可能触发，但不代表正常操作成功；持续出现仍需要进一步排查。鼠标移动及提示状态更新已不再同步等待输入线程。

悬浮帮助或提示的高度最多为当前屏幕可用高度的 1/3，超出时自动显示竖向滚动条。可拖动滑块、点击滚动箭头、使用鼠标滚轮，或用 PageUp/PageDown、上下方向键、Home/End 查看完整内容，Esc 关闭。长提示不会按普通提示计时自动消失。

## 分区表达式

格式：`x|y|width|height[|monitor]`。例如 `0|0|50sw|50sh` 表示左上四分之一。

分区名称不能与内置动作或其别名重名（例如 `Quit`、`Help`、`Pin`），以免快捷键含义冲突。已有冲突需要手动重命名分区及引用它的绑定，程序会保留配置并提示错误。

| 单位 | 含义 |
| --- | --- |
| sw / sh | 工作区宽 / 高的百分比 |
| ww / wh | 当前窗口宽 / 高的百分比 |
| vw / vh | 虚拟桌面宽 / 高的百分比 |
| 无单位 | 像素 |

`50sw-8` 表示半个工作区宽减 8 像素。屏号省略或为 0 时跟随鼠标；含 vw/vh 时使用虚拟桌面原点。

九宫格从左上到右下编号 1–9。想设置某块屏幕上的区块，只需要将对应的屏幕编号乘10，再加上格子号即可，例如想设置屏幕3的左下角，编号就是 `3*10+7=37`：

```toml
[grid]
7 = "LeftBottom"
37 = "Center"
```

屏幕专属映射优先，其余屏幕使用通用格号。

## 内置动作与指令

指令和预设按相同规则规范化名称（含大小写、首尾空白和全角字母数字）；区域的显示名称保留原写法。内置动作由程序定义，配置中的 `[keys]`、`[commands]` 只负责绑定，不必另写定义。命令不能与区域重名，也不能改变内置动作或别名的含义；`Pin = "Top"` 这样的同义映射仍可保留。冲突命令会使配置更新被拒绝，原文保留。

| 动作 | 别名 | 作用 |
| --- | --- | --- |
| Version | Ver | 显示版本 |
| Help | H | 显示帮助 |
| Top | Pin | 置顶 / 取消置顶 |
| Ignore | Exclude | 忽略窗口 |
| Guide | — | 显示 / 隐藏十字线 |
| MouseCast / KeyCast | — | 开启 / 关闭鼠标标注、键盘标注 |
| Horizontal | — | 只显示水平十字线，再次调用隐藏；默认 Alt + Minus |
| Vertical | — | 只显示垂直十字线，再次调用隐藏；默认 Alt + Backslash |
| Cross | — | 显示两条十字线，再次调用隐藏；默认 Alt + Equal |
| Borders | — | 显示 / 隐藏分区框线 |
| Time / Monitor | Screen（Monitor） | 显示时间 / 屏幕编号 |
| Command / Settings / Reload | — | 输入指令 / 打开设置 / 重载配置 |
| Restart / Quit | Reboot / Exit | 重启 / 退出 |

`gesture` 指定鼠标操作使用的 Alt 侧；`horizontal`、`vertical` 配置节分别设置十字线两轴。Esc/Escape 不可用作区域名或命令名。快捷键禁止绑定 Tab、F4、Space、Enter、PrintScreen、方向键、PageUp/PageDown、Home/End、Esc 及修饰键，以保留常用系统 Alt 快捷键和程序导航操作；`VK:xx` 同样受限。应用内的字母快捷键仍可配置。按键的不同写法（如 Q 与 VK:51）也不能重复定义，包括空绑定。

## 命令行与管道

```powershell
.\winsizep.exe --name notepad.exe --preset Center
.\winsizep.exe --pid=123 --location 100,200 --size 900,600
.\winsizep.exe --hwnd 0x1234 --top on
.\winsizep.exe --settings
.\winsizep.exe --check
.\winsizep.exe Ver
123, 456 | .\winsizep.exe --stdin --preset Center
'--name notepad.exe --preset LeftTop' | .\winsizep.exe --stdin
```

窗口筛选支持 `--pid`、`--hwnd`、`--name`、`--class`、`--title`，不同条件同时匹配。重复同类条件保留第一个；匹配多个可见窗口时使用枚举到的第一个。省略筛选条件时操作前台窗口。直接坐标覆盖预设坐标。

`--stdin` 每行接受一组参数或单个 PID，空行跳过；无参数且 stdin 是管道时也会读取。窗口操作不受常驻实例锁影响。成功信息写 stdout，错误写 stderr，出错返回非零退出码。

语法无法解析时才尝试修复字符串外的常见中文标点；字符串中的标点保留。字段值错误时回退该字段并提示；无法恢复的语法错误保留原文件。GUI 与文件同时修改时，文件中的冲突字段优先，其余 GUI 更改保留。

## 中文与编码

设置界面的普通文本控件、区域名称、字体名称、提示格式以及排除规则中的程序名、窗口类名和标题支持中文。命令行参数中的中文标题、程序名、类名、区域名和程序所在目录也按 Unicode 处理。数字、颜色、分区表达式、按键名以及配置中的固定选项仍须使用各自规定的语法；配置里的中文区域名称等 TOML 键需要加引号，例如 `"左上区域" = "0|0|50sw|50sh"`。

全局“输入指令”模式目前只接收英文字母、数字、空格、连字符和下划线，不支持中文输入法提交或粘贴。`[commands]` 的命令名称也仅允许这些 ASCII 字符；中文命令名在设置中无法保存，手动写入后会被配置恢复逻辑移除并提示。中文区域可以绑定快捷键、通过 `--preset "左上区域"` 调用，或配置英文别名，例如 `Zuoshang = "左上区域"`。

配置读取支持 UTF-8（有或无 BOM）、带 BOM 的 UTF-16LE 和 UTF-16BE；不支持 GBK/CP936、无 BOM 的 UTF-16 或 UTF-32。创建或保存配置时统一写为无 BOM 的 UTF-8，中文内容保留，但不会保留原来的 UTF-16 编码。无法解码的配置会报错并保留原文件，请先用编辑器转换为 UTF-8。

系统默认代码页与文件编码是两回事：程序的界面、路径和命令行参数使用 Unicode 接口，不依赖 Windows“非 Unicode 程序的语言”所设置的 ANSI 代码页。即使系统默认代码页为 CP936，配置文件仍需使用上述受支持的编码。中文能否完整显示还取决于已安装字体和回退字体是否包含所需字形。

`--stdin` 管道和重定向输入必须是 UTF-8，不会自动识别 GBK 或 UTF-16；重定向的标准输出和错误输出也使用 UTF-8。调用脚本或上游程序需要按 UTF-8 编码发送数据，如果在发送前已将中文替换成问号，程序无法恢复原文。

## 构建

Windows，Rust MSVC 工具链与 Windows SDK：

运行环境为 Windows 10 1703 或更新版本，仅支持 x64；构建需要 Rust 1.88 或更新版本，目标为 `x86_64-pc-windows-msvc`。程序采用便携配置，目录必须允许当前用户写入；请放在个人可写目录，而不是只读目录或受保护的 Program Files。

```powershell
cargo build --release
cargo test
```

程序位于 `target/release/winsizep.exe`。版本号只修改 `Cargo.toml` 的 `[package].version`，命令输出和 Windows 资源由此生成。

显式指定的屏号必须对应已连接显示器，否则会报告错误。无效区域表达式在预览中单独跳过并提示原因。跨屏定位会核对最终可见边框；目标窗口未接受请求的位置尺寸时会报告超时。

交互式多屏回归测试：`cargo test multi_monitor_regressions -- --ignored --test-threads=1`。缺少第二屏或不同 DPI 的显示器时，相应测试自动输出 `SKIPPED` 原因并返回，其他用例仍会执行。设置 `WINSIZEP_TEST_SINGLE_MONITOR=1` 可在不改变显示布局的情况下验证单屏跳过路径。
