# WinSizeP

中文 | [English](README.en.md)

Windows 窗口管理工具。通过 Alt 和鼠标快速移动、缩放、分区排列窗口，也支持多屏、窗口置顶和录屏时的键鼠操作标注。

## 快速上手

运行 `winsizep.exe`，从托盘菜单打开设置或暂停操作捕获。

**长按或双击左 Alt，进入窗口操作状态。** 松开 Alt 后仍可操作；按 Esc 取消，拖动中的窗口会恢复原来的位置和大小。

| 操作 | 效果 |
| --- | --- |
| 左键拖动 / 右键拖动 | 移动 / 缩放窗口 |
| 左键点击分区 | 累计选择，Enter 确认 |
| 右键点击分区 | 立即移动到该分区 |
| 拖动高亮的窗口共边 | 联动调整相邻窗口大小 |
| Q/W/E、A/S/D、Z/X/C | 选择九个默认分区 |
| 主键盘 1～4 | 选择四个默认分区 |
| 中键点击 / F | 居中 / 最大化 |
| P / L | 切换置顶 / 十字线 |
| M / K | 切换鼠标 / 键盘操作标注 |
| 反撇号键 | 打开命令框，输入分区名称或命令 |
| H | 查看当前快捷键帮助 |

以上操作均在 Alt 激活后使用。快捷键、鼠标按键、分区和界面字体可在设置中调整，下拉框支持搜索，修改自动保存。更多用法见托盘“帮助”和设置项说明。

控制管理员窗口时，请以管理员身份运行 WinSizeP。

## 构建

需要 Windows x64、Rust 1.88+ MSVC 工具链和 Windows SDK。

```powershell
cargo build --release
cargo test
```

生成程序：`target/release/winsizep.exe`。支持 Windows 10 1703 及更新版本。
