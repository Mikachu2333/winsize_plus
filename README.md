# WinSizeP

中文 | [English](README.en.md)

Windows 窗口管理工具，通过 Alt 快捷键和鼠标操作快速移动、调整和排列窗口，适合多屏工作、录屏和演示。

## 功能

- 移动、缩放、居中和最大化窗口，支持多显示器。
- 按实际屏幕分区排列窗口，支持累计选择、自定义分区与快捷键。
- 窗口置顶、十字线和待操作窗口标示。
- 鼠标与键盘操作标注，方便录屏和演示。
- 托盘暂停 / 启用捕获；设置自动保存，界面跟随 Windows 亮暗主题。
- 支持命令行操作、自动启动和管理员模式。

## 使用

运行 `winsizep.exe`，从托盘菜单打开设置。默认长按或双击左 Alt 进入同一操作状态，松开 Alt 后仍可操作。左键累计选择实际分区，右键立即应用，Enter 确认，Esc 取消；空选 10 秒退出，最后一次选择变更后 3 秒自动应用。激活键、鼠标总开关、单击／拖动按键和联动开关均在“窗口操作”中设置。鼠标操作针对触发时的前台窗口，共边联动针对轮廓标出的相邻窗口组。

长按 Alt 进入捕获或执行 WinSizeP 操作后，松开 Alt 会抑制前台软件的菜单激活。短按 Alt 和捕获前的原生快捷键保留原有行为。

| 常用操作 | 作用 |
| --- | --- |
| Alt + 左键拖动 | 移动窗口 |
| Alt + 右键拖动 | 调整窗口大小 |
| Alt 触发后左键 / 右键点击 | 累计选择 / 立即应用实际分区 |
| Alt + 中键点击 | 在鼠标所在屏幕居中 |
| Alt + F | 最大化；无法最大化时填满工作区 |
| Alt + Q/W/E、A/S/D、Z/X/C | 使用九个分区预设 |
| Alt + P | 置顶 / 取消置顶 |
| Alt + L | 显示 / 隐藏十字线 |
| Alt + M / Alt + K | 切换鼠标 / 键盘标注 |
| Alt + H | 查看当前快捷键帮助 |
| Esc | 关闭提示或取消操作 |

可在设置中调整快捷键、鼠标操作、分区和标注。更多操作见托盘“帮助”。控制管理员窗口时，需要以管理员身份运行 WinSizeP。

点击快捷键名称框后按一个键录入，主键盘 `1` 与小键盘 `Numpad1` 分别保存对应 VK；再次点击可重录，Ctrl+V 可粘贴名称或 `VK:xx`。设置下拉框可输入文字搜索，方向键只浏览，Enter 或鼠标选择确认，Esc 恢复原值。文本按 Enter 或离开字段后保存，其他选项确认后自动保存；每行显示未保存、输入错误或已保存状态。

框线显示模式可选“激活后显示全部”“累计选择后显示”“不显示框线”；三种模式均支持选区。设置页按 Esc 会同步关闭预览开关。屏幕分区与快捷键可通过“查看快捷键”和“编辑分区”直接互跳。

Alt 触发后按反撇号打开命令输入框，框内显示目标窗口及屏幕，支持中文输入法、光标编辑和粘贴。输入分区名称（如 `1/4`）、表达式（如 `0|0|100sw|50sh`）或命令后按 Enter；表达式分隔符也接受 `｜` 和 `、`。Esc、失焦或暂停程序会取消命令；输入错误时保留文字，详细错误可滚动查看。

默认分区包括从左到右、从上到下编号的 `1/9`～`9/9`（Q/W/E、A/S/D、Z/X/C）和 `1/4`～`4/4`（主键盘数字 1～4，小键盘独立）。分区使用屏幕工作区；多个选择按最小外接矩形合并。旧配置中的完整默认布局自动迁移，自定义布局保留。

开启“联动缩放相邻窗口”后，Alt 激活时拖动高亮共边可联动缩放，悬停时轮廓标出参与窗口。默认左键或右键拖动均可；其他位置继续移动或缩放原窗口。相邻边允许 5 个物理像素以内的间隙或重叠，共享边长度须超过屏幕工作区对应宽高的 1/16。品字形等排列按同方向相连的公共边联动；交点按起始拖动方向决定调整轴。任一窗口达到尺寸限制时整组停止。普通移动、普通缩放和联动缩放均可按 Esc 恢复拖动前的位置和大小。

配置文件 `winsizep_config.toml` 保存在程序同目录，始终以普通用户权限读取、保存和打开。权限不足时会显示具体文件和错误；点击设置窗口左下角的错误提示可查看完整内容。并发保存冲突会保留 `.conflict.toml` 文件，供核对外部修改。

保存错误提示显示 10 秒，点击后打开的详情消息框需手动关闭。连续保存提前替换旧提示时，会先隐藏旧提示，间隔 100 ms 后显示新提示；首次提示和自然到期后的提示立即显示。

管理员自启动要求程序及其父目录无法被普通用户替换。不满足条件时会拒绝注册并尝试移除旧的自启动任务，可关闭管理员自启动后继续使用。

## 命令行

```powershell
.\winsizep.exe --name notepad.exe --center
.\winsizep.exe --pid 123 --location 100,200 --size 900,600
.\winsizep.exe --help
```

## 构建

需要 Windows x64、Rust 1.88+ MSVC 工具链和 Windows SDK。支持 Windows 10 1703 及更新版本。

```powershell
cargo build --release
cargo test
```

生成程序：`target/release/winsizep.exe`。

Debug 与 Release 使用独立的实例及设置窗口标识，可同时运行；Debug 标题和托盘提示会标明构建类型。两种构建的自动启动任务也分别保存。
