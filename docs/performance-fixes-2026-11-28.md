# 新功能性能修正

按性能审查逐项实施；测量使用 Release 构建和相同的隔离探针。下表是本机结果，中位耗时用于比较；用户实际窗口数量、字体和显示配置会影响数值。

| 项目 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 共边窗口快照，9 个可见窗口 | 20.8 ms | 0.25 ms |
| 30 次滚轮输入积压后的 Esc 响应 | 569 ms | 5.7 ms |
| 300 分区首次构建 | 1597 ms | 71 ms |
| 300 分区滚动 | 159 ms | 7.5 ms |
| 300 分区表达式编辑，不含保存 | 27.5 ms | 0.04 ms |
| 2000 项下拉框筛选 | 37.6 ms | 31.4 ms |
| 2000 项下拉框恢复 | 56.2 ms | 48.5 ms |
| UI 字体变化 | 95.4 ms | 31.1 ms |

## 修正内容

1. 屏幕工作区与 DPI 按显示器、DPI 上下文缓存。显示配置变化时通过跨线程版本号失效；避免每个窗口、每次鼠标移动都创建 DPI 查询窗口。
2. 联动更新按目标进程和 UI 线程分流，保留每窗口最新矩形，公平调度同线程窗口。不同进程测试中，1500 ms 的慢窗口不再阻塞正常窗口：400 ms 检查时正常窗口已完成。新会话覆盖旧会话，完成和错误状态可查询；超过 2 秒的更新向调用方报告超时。已进入外部窗口的系统调用无法强行中断，因此复用同一线程通道，并限制通道数量，避免每次拖动额外堆积线程。
3. 连续滚轮逐条更新候选和时间状态，但高亮及提示按 16 ms 合并绘制。Esc 清除尚未绘制的候选，保持平滑滚轮余量、候选保持和截止时间规则。
4. 窗口拖动使用独立 120 FPS 帧钟，十字线继续使用自己的配置。
5. 大于 64 个分区时，设置页按需创建视口内行并隐藏视口外控件。远处搜索、关联跳转会先创建目标行；已编辑内容在滚动返回后保留。表达式编辑仅校验当前值，保存时再完整校验配置。
6. 下拉框共享不可变选项及预计算搜索文本；候选不变和重复恢复直接复用。需要重建时，预留原生列表容量，并暂时关闭列表和组合框重绘。
7. 常驻程序的窗口位置验证、还原和拖动初始化移到单一几何工作线程。UI 线程只投递任务和最新指针位置；新操作、Esc、暂停可使旧任务的后续步骤失效。联动尺寸约束采用整组 200 ms 预算。命令行入口继续同步返回操作结果。
8. 字体变化只立即更新当前页，已缓存的隐藏页在再次进入时重建，避免给全部隐藏控件发送字体消息。

## 验证

- 147 项常规测试通过，Clippy 无警告。
- 完整设置页测试、300 分区按需创建／滚动／编辑／保存、搜索下拉框确认／取消、字体切换回归通过。
- 真实窗口测试覆盖三窗口横向共边、两窗口竖向共边、慢窗口、连续拖动覆盖、提前松开和 Esc 恢复。
- 异步位置应用测试中，窗口故意延迟 300 ms，界面提交约 53 μs，实际完成约 386 ms；最终矩形仍经过稳定性确认。
- 命令输入开关 120 次后，GDI／USER 对象均保持在预热后的数量。
