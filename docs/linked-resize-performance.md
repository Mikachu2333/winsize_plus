# 联动缩放更新队列

2026-11-28，在三个独立进程窗口组成的品字形布局上测量。

旧实现每帧对每个窗口调用 `SetWindowPos(SWP_ASYNCWINDOWPOS)`。目标窗口处理尺寸变化较慢时，仍会逐一处理已过时的位置，停止拖动后持续追赶。

现将待提交的整组矩形合并为最新一组，独立工作线程同步提交；主线程继续接收输入。取消以原始位置覆盖待处理位置，拖动对象释放后工作线程完成最后一组再退出。每帧坐标换算使用拖动开始时记录的边框。

测试给被动窗口的尺寸处理增加 40 ms 延迟，每隔 5 ms 提交一次，共 40 次：

| Release 测量 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 提交输入耗时 | 215 ms | 211 ms |
| 输入停止后追赶耗时 | 1515 ms | 72 ms |
| 被动窗口处理更新数 | 40 | 5 |

测试同时检查最终矩形、三窗口横边联动、两窗口竖边联动、积压期间取消恢复，以及释放拖动对象后最终恢复位置不被旧更新覆盖。
